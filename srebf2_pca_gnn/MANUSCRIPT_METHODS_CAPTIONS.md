# Manuscript integration — PCA and exploratory GNN

## Methods: RNA-seq principal component analysis

Sample-level principal component analysis will be performed using the 12-sample HeLa SREBF2-knockout RNA-seq count matrix (GSE267018), with sample identifiers and experimental group labels from `metadata/GSE267018_analysis_samples.tsv`. Low-count genes are filtered and 2,000 highly variable expressed genes selected; each sample is projected into two-dimensional principal-component space. The preferred analysis applies an unsupervised (`blind=TRUE`) variance-stabilizing transformation using DESeq2 before PCA. A secondary Python implementation uses log2(CPM+1), which is an exploratory normalization and is not equivalent to DESeq2 VST. Points are annotated by genotype (WT or KO) and treatment (FBS or cholesterol depletion), and principal-component variance fractions are reported. A sensitivity plot excludes SRR28966285; this is an exploratory assessment of sample geometry rather than a reason to exclude it from primary differential-expression modeling. No claims about group statistical significance follow from PCA visualization.

## Methods: exploratory functional-association graph representation learning

The human STRING functional-association network will be constructed using the 12 leading-edge cholesterol-biosynthesis genes as seed proteins (taxon 9606), a combined association-score threshold of 0.700, and an expanded neighborhood of up to 70 additional proteins. The query, date, and returned edges are archived. Since the five-enzyme network is fully connected (5 proteins; 10 associations), it cannot support an informative train/test edge-reconstruction experiment. For the expanded graph, a connectivity-preserving spanning forest is retained in the training edge set, with approximately 10% of remaining edges assigned to validation and 15% to testing. A two-layer graph convolutional autoencoder learns 16-dimensional latent node embeddings using graph features derived from the **training** network; withheld graph edges are not used to compute features or message passing. Edge scores are evaluated with ROC AUC and average precision relative to a common-neighbors baseline using the same positive and negative pair sets. An independent SREBF2-knockout log2 fold-change column is overlaid after model fitting to visualize selected gene locations, without using gene-response labels during model training. Outputs are exploratory associations within the STRING resource, not validated SREBP2 targets, confirmed biochemical interactions, or predictions of transcriptional responses.

## Publication decision

A genuine sample PCA is reasonable in main Figure 1 or Supplementary Figure S1. The verified five-gene STRING network is suitable as descriptive supporting evidence or a supplement. A GNN embedding should not become a central paper figure unless it shows a reproducible advantage over simpler methods across independent splits and addresses an additional biological question (e.g. appropriately validated response prediction); a high-dimensional visualization is not evidence of mechanism by itself.
